# 10 פרומפטים מוכנים - אחד לכל סגנון

מעתיקים, מחליפים את הנתיב לסרטון, מדביקים ב-Claude Code. כל פרומפט מפעיל את `/video-styles`.

**טיפ:** צלם בטלפון על חצובה, אור מהחלון מולך, 4K אם אפשר (חובה לסגנון 3).

---

### 1. מסלול
```
/video-styles סגנון 1 - מסלול. הסרטון: /path/to/video.mov
תמלל בעברית, זהה את השלבים שאני מונה, וצייר מסלול שעובר מאחוריי עם תחנה ממוספרת לכל שלב בדיוק כשאני אומר אותו. ייצא MP4.
```

### 2. שער של מגזין
```
/video-styles סגנון 2 - שער של מגזין. הסרטון: /path/to/video.mov
תהפוך אותי לשער של מגזין: שם המגזין ענק מאחורי הראש שלי, ו-3-5 כותרות שער מתוך מה שאני אומר נכנסות לפי הזמן. תוסיף מספר גיליון, תאריך וברקוד. ייצא MP4.
```

### 3. אפקט Vertigo
```
/video-styles סגנון 3 - אפקט Vertigo. הסרטון: /path/to/video.mov
תמצא את המשפט הכי חזק בסרטון ותעשה עליו dolly zoom - אני נשאר באותו גודל והחדר מאחוריי מתרחק. פעם אחת בלבד, עם סאונד whoosh. ייצא MP4.
```

### 4. קו מצויר
```
/video-styles סגנון 4 - קו מצויר. הסרטון: /path/to/video.mov
תוסיף שרבוטי טוש לבן וצהוב שמצטיירים על המסך - עיגול, חץ, קו תחתון, מחיקה - על כל רעיון מרכזי, עם 1-4 מילים בכתב יד. עיגול אחד שעובר מאחורי הראש. ייצא MP4.
```

### 5. קיר כותרות
```
/video-styles סגנון 5 - קיר כותרות. הסרטון: /path/to/video.mov
תבחר 6-8 משפטים חזקים מהסרטון ותהפוך אותם לפתקים וגזירי נייר שנדבקים על הקיר מאחוריי, אחד אחרי השני, עם סלוטייפ וצל. פתק ראשון בשנייה הראשונה. הקיר מתמלא עד הסוף. ייצא MP4.
```

### 6. קולאז' נייר
```
/video-styles סגנון 6 - קולאז' נייר. הסרטון: /path/to/video.mov
תעשה לי לוק של קולאז' גזירי נייר: מסגרת סטיקר לבנה סביבי, גזירי נייר קרועים מאחוריי, כותרות מאותיות גזורות בסגנון מכתב כופר, ומעברי קריעת נייר. תחושה של סטופ-מושן. ייצא MP4.
```

### 7. אותיות זכוכית
```
/video-styles סגנון 7 - אותיות זכוכית. הסרטון: /path/to/video.mov
תבחר 3-4 מילים חזקות מהסרטון ותציג כל אחת באותיות זכוכית ענקיות עם פס אור שעובר עליהן - אחת מאחוריי, אחת לפניי. לוק פרימיום. ייצא MP4.
```

### 8. קו חי
```
/video-styles סגנון 8 - קו חי. הסרטון: /path/to/video.mov
קו אחד רציף שחי לאורך כל הסרטון ולא נשבר - הופך לקו תחתון, לחץ, לגרף עולה, לדופק - לפי מה שאני אומר. כל מספר שאני אומר רוכב על הקו. ייצא MP4.
```

### 9. צ'אט שמקליד
```
/video-styles סגנון 9 - צ'אט שמקליד. הסרטון: /path/to/video.mov
תהפוך את הסרטון לשיחת צ'אט לידי: שלוש נקודות של הקלדה, ואז בועה עם השאלה או ההתנגדות, ואני עונה בקול. בועות בעברית RTL, מקסימום 4 על המסך. ייצא MP4.
```

### 10. טיסה במפה
```
/video-styles סגנון 10 - טיסה במפה. הסרטון: /path/to/video.mov
כשאני מדבר על המעבר מ-[נקודה א] ל-[נקודה ב], תפתח מפה, מטוס ממריא, טס בקשת עם שובל ונוחת עם פין. חזור אליי תוך 6 שניות מקסימום. ייצא MP4.
```

---

### לא יודע איזה סגנון?
```
/video-styles תבחר אתה. הסרטון: /path/to/video.mov
תקרא את התמלול, תמליץ על סגנון אחד מתוך ה-10 עם סיבה במשפט אחד, ותחכה לאישור שלי לפני שאתה בונה.
```
