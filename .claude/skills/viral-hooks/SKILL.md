# Viral Hooks

The library lives in `references/hooks.md` - 100 fill-in-the-blank templates in 13 categories.

## How to use

1. Get the **topic** and **audience** (read `brand/brand-brief.md` if it exists).
2. Pick 3-5 categories that fit the angle:
   - Have results/proof -> **Receipts**, **Transformation**
   - Have a hot take -> **Contrarian**, **Comparison**
   - Teaching something -> **How-To**, **Numbers & Lists**, **Mistake**
   - Personal moment -> **Story**, **Challenge & Experiment**
   - Niche audience -> **Callout**, **Insider Secret**
   - Timely topic -> **Urgency & Trend**
   - Anything -> **Curiosity Gap**
3. Read `references/hooks.md` and fill the templates with specifics. Never output a template with blanks still in it.
4. Return 10 filled hooks by default:

```
TOPIC: <topic> | AUDIENCE: <who>

1. <hook>  - [Category #template-number]
2. ...

TOP PICK: #<n> - <one line why>
```

## Filling rules
- Replace every `[blank]` with something specific: real numbers, real timeframes, the audience's words.
- Under 12 words when spoken. Cut filler ("so", "basically", "honestly").
- Only use numbers the user gave you or that are in the brief - no invented receipts.
- Adapt to the language of the post. In Hebrew, rewrite the pattern natively, don't translate word for word.
- Variety: never return 2 hooks from the same template.
- No em-dashes.

## Visual hook pairing (video)
A hook is text + visual. When the format is video, add a one-line visual for the top pick:
- Start mid-action, not with a wave
- Show the result first, then rewind
- Text on screen that says the hook even with sound off
