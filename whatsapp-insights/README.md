# המראה - מה הוואטסאפ שלך יודע עליך

ליד מגנט חינמי בשני מסלולים:

- **ווב (`web/`)** - דף נחיתה + כלי שמנתח ייצוא צ'אט מוואטסאפ. הכל רץ בדפדפן, שום הודעה לא עולה לשרת. אתר סטטי, בלי שרת ובלי מפתחות API.
- **סקיל ל-Claude Code (`.claude/skills/whatsapp-insights/`)** - קורא את כל הצ'אטים מוואטסאפ דסקטופ במק (או קבצי ייצוא בכל מחשב), ומוסיף ניתוח עומק עם ה-Claude של המשתמש.

שני המסלולים משתמשים באותו מנוע ובאותו דשבורד (`web/assets/`).

## מבנה

```
whatsapp-insights/
  web/                    <- את התיקייה הזאת מעלים לאחסון
    index.html            דף נחיתה + טופס
    app.html              הכלי
    privacy.html          פרטיות
    config.js             קישורים, רב מסר, כתובת האתר  <- לערוך לפני השקה
    report-template.html  התבנית של הדוח המקומי בסקיל
    assets/               מנוע, דשבורד, עיצוב
    downloads/            ה-ZIP של הסקיל (נבנה ע"י scripts/build.sh)
  scripts/build.sh        מעתיק את הנכסים לסקיל ובונה את ה-ZIP
  tests/                  בדיקות JS + Python + קבצי דוגמה
.claude/skills/whatsapp-insights/   הסקיל עצמו
```

## לפני השקה - צ'קליסט

1. **איסוף מיילים (חובה).** בלי זה המיילים לא נשמרים בשום מקום.
   - ברב מסר: יוצרים טופס עם שדות שם, מייל (ואופציונלי: מגדר, ילדים, עיסוק, מקור).
   - בהגדרות הטופס: דף התודה = `https://<הדומיין>/app.html`.
   - מעתיקים מקוד ההטמעה את כתובת ה-`action` ואת ה-`name` של כל שדה, ומדביקים ב-`config.js` תחת `ravMesser`.
   - חלופה: webhook של Make/Zapier ב-`leadWebhook`.
2. **קישורים למוצרים** ב-`config.js` תחת `links` (האבא מבצעי, ליווי, סדנאות, כללי).
3. **אחסון.** מעלים את התיקייה `web/` כמו שהיא:
   - Netlify: גוררים את התיקייה ל-app.netlify.com/drop, או
   - Cloudflare Pages: מחברים את הריפו, תיקיית פלט `whatsapp-insights/web`, בלי פקודת build.
   - מחברים תת-דומיין (למשל `chat.yosha.co.il`) ברשומת CNAME אצל מי שמנהל את ה-DNS.
   - Vercel בתוכנית החינמית אסור לשימוש מסחרי.
4. **זרניו.** מילת קוד בריל → דיירקט עם הקישור לדף הנחיתה, עם `?src=<שם הריל>` כדי לדעת איזה ריל הביא כל ליד.
5. **בדיקה על טלפון אמיתי.** אייפון + אנדרואיד, גם מתוך הדפדפן של אינסטגרם: ייצוא צ'אט, העלאה, דוח, שיתוף כרטיס.
6. **בדיקת הסקיל על מק אמיתי** לפני שמפרסמים אותו (ראו "מה עוד לא נבדק").

אחרי כל שינוי ב-`web/assets/` או ב-`config.js`, מריצים `whatsapp-insights/scripts/build.sh` כדי לעדכן את הסקיל ואת ה-ZIP.

## מה עוד לא נבדק

- **הסקיל מול וואטסאפ דסקטופ אמיתי.** נבדק רק מול מסד נתונים מזויף באותו מבנה. צריך לאמת: קודי סוגי ההודעות, שמות קבוצות, כמה היסטוריה יש בדסקטופ, והרשאת הגישה של macOS.
- **הדפדפן של אינסטגרם.** בחירת קבצים ושיתוף הכרטיס.
- **המשקלות של הטיפוסים.** כוילו על נתוני דמו. אחרי 20-30 משתמשים אמיתיים כדאי לכייל מחדש (`analyze` ב-`web/assets/engine.js`).
- **משפטי.** דף הפרטיות נכתב בשפה פשוטה ולא עבר עו"ד.
